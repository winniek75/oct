【写真の入れ方】octobicycle.com（WordPress管理画面 → メディアライブラリ）から
写真をダウンロードし、以下のファイル名にリネームしてこのフォルダに入れるだけで反映されます。

  hero.jpg         … トップの背景（横長・雰囲気のある走行写真や店舗前がおすすめ／横2000px前後）
  bike-ebike.jpg   … eバイクの写真（ARCHON A03 など）
  bike-cruiser.jpg … クルーザーの写真（BRONX BUGGY STRETCH など）
  bike-city.jpg    … シティバイクの写真
  shop.jpg         … 店舗内観・スタッフ写真（会社紹介欄）
  area1.jpg / area2.jpg / area3.jpg … 周辺のおすすめスポット写真
  ogp.jpg          … SNSでシェアされた時の画像（1200x630px）
  favicon.png      … ブラウザタブのアイコン（512x512px）

※写真が無い項目は自動でプレースホルダー画像が表示されるので、後からでもOKです。
※ファイルサイズは1枚500KB以下を目安に（https://squoosh.app で無料圧縮できます）
